Проект содержит 12 SQL-запросов к учебной базе данных dvdrental (PostgreSQL). Задачи выстроены от базовых SELECT до оконных функций и накопительных итогов.

Что демонстрирует проект:

Построение цепочек JOIN (от 2 до 5 таблиц) по нормализованной схеме.

Агрегация и фильтрация групп: GROUP BY, HAVING, SUM, AVG, COUNT.

Поиск отсутствующих записей через LEFT JOIN + IS NULL.

Оконные функции: RANK(), ROW_NUMBER(), LAG(), SUM() OVER.

Понимание порядка выполнения: WHERE → GROUP BY → оконные функции → ORDER BY / LIMIT.

Пагинация через LIMIT + OFFSET.

Стек: PostgreSQL, DBeaver.

Структура: каждый .sql-файл содержит условие задачи в комментарии и готовый запрос. Файлы пронумерованы по возрастанию сложности.
